🐴 oh-my-harness

CLAUDE.md is a request. oh-my-harness is enforcement.

npx oh-my-harness init "React + FastAPI, TDD enforced, lint on save"
★ Star on GitHub npm vs. other tools
Agent commits while tests fail⛔ Blocked
Agent edits foo.ts before foo.test.ts⛔ Blocked (TDD guard)
Agent runs rm -rf / or any pattern you list⛔ Blocked
Agent writes into node_modules/, dist/, a lockfile⛔ Blocked
Agent commits on a branch already merged⛔ Blocked
Agent edits its own hooks to switch guardrails off⛔ Blocked
Agent saves a file✔ auto-lint
Agent pushes a branch✔ auto-PR

Agents read instructions and forget them halfway through a long session. A rule in markdown is a suggestion; a PreToolUse hook that returns {"decision":"block"} is a fact. oh-my-harness writes both, from one harness.yaml, for Claude Code, Codex and Pi at once, and fails CI when they drift.
