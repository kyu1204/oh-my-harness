# L-01 ledger.ts — 원장 파서

## 목적
원장(WORKPLAN.md) 텍스트에서 체크박스·BLOCKED 마커를 세고, 해시·diff를 제공하는 순수 모듈.

## 파일
- 구현: `src/loop/ledger.ts`
- 테스트: `tests/unit/loop-ledger.test.ts`

## 시그니처
```ts
export interface LedgerCounts { unchecked: number; checked: number; blocked: number }
export function parseLedger(text: string): LedgerCounts
export function hashLedger(text: string): string           // sha256 hex (node:crypto)
export interface LedgerDiff { ticked: number; newBlocked: number }
export function diffLedger(before: LedgerCounts, after: LedgerCounts): LedgerDiff
```

## 규칙
- 체크박스 라인: `^\s*[-*]\s+\[( |x|X)\]` — 공백=unchecked, x/X=checked.
- blocked: 라인에 `BLOCKED:` 문자열 포함(대소문자 구분). **unchecked이면서 BLOCKED인 라인은 unchecked에 포함하지 않는다**(미완료 태스크 수 = unchecked, BLOCKED 제외).
- `ticked = max(0, after.checked - before.checked)`, `newBlocked = max(0, after.blocked - before.blocked)`.

## 테스트 케이스
1. 빈 문자열 → 0/0/0.
2. `- [ ] a`, `- [x] b`, `- [X] c`, `* [ ] d` → unchecked 2, checked 2.
3. `- [ ] e BLOCKED: no work order` → blocked 1, unchecked 0.
4. 체크박스 아닌 라인의 `BLOCKED:` 언급(예: 프로토콜 설명문)은 blocked에 세지 **않는다** — 체크박스 라인만 대상.
5. hashLedger 동일 입력 동일 출력, 한 글자 차이 → 다름, 64자 hex.
6. diffLedger: checked 1→3 → ticked 2; blocked 0→1 → newBlocked 1; 감소는 0.
