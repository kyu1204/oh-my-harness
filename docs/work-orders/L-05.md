# L-05 runtime.ts — 런타임 argv·턴 실행

## 목적
런타임별 argv 생성(순수)과 한 턴 실행(spawn, 로그 파일, timeout, stop 요청 시 SIGTERM→SIGKILL).

## 파일
- 구현: `src/loop/runtime.ts`
- 테스트: `tests/unit/loop-runtime.test.ts`

## 시그니처
```ts
export type LoopRuntime = "claude" | "codex" | "pi";
export function buildTurnArgv(runtime: LoopRuntime, model: string, prompt: string): string[]  // [bin, ...args]
// claude → ["claude","--model",model,"--dangerously-skip-permissions","-p",prompt]
// codex  → ["codex","exec","--model",model,"--dangerously-bypass-approvals-and-sandbox",prompt]
// pi     → ["pi","--print","--no-session","--model",model,prompt]
export interface TurnOptions { argv: string[]; cwd: string; env: NodeJS.ProcessEnv; logPath: string; timeoutMs: number; shouldStop: () => boolean; pollMs?: number; graceMs?: number; onSpawn?: (pid: number) => void }
export interface TurnResult { status: number | null; signal: NodeJS.Signals | null; timedOut: boolean; stoppedByRequest: boolean; tail: string }
export function runTurn(o: TurnOptions): Promise<TurnResult>
```

## runTurn 규칙
- `spawn(argv[0], argv.slice(1), { cwd, env, stdio: ["ignore", fd, fd] })` — fd는 `openSync(logPath, "a")`; **detached 없음**(슈퍼바이저 그룹 유지), **shell 없음**. `onSpawn(pid)` 호출.
- 타이머: `timeoutMs` 경과 → `kill("SIGKILL")`, `timedOut=true`.
- `pollMs`(기본 2000)마다 `shouldStop()` → true면 `kill("SIGTERM")`, `graceMs`(기본 10000) 후 살아있으면 `SIGKILL`, `stoppedByRequest=true`.
- 종료 시 fd 닫고 로그 파일 마지막 4096바이트를 `tail`로 반환. ENOENT(바이너리 없음)는 status null, signal null, tail에 에러 메시지 기록 후 반환(throw 금지).
- 타이머·인터벌은 반드시 clear(테스트 프로세스 행 방지).

## 테스트 케이스
1. argv 3런타임 정확히 일치(배열 동등).
2. stub 스크립트(`#!/usr/bin/env bash\necho out; echo err >&2; exit 3`) → status 3, tail에 out·err, 로그 파일에도 기록.
3. `sleep 30` stub + timeoutMs 500 → timedOut true, signal SIGKILL, 2초 내 반환.
4. `trap '' TERM; sleep 30` stub + shouldStop이 300ms 뒤 true, pollMs 100, graceMs 200 → stoppedByRequest true, signal SIGKILL, 2초 내 반환.
5. 존재하지 않는 바이너리 → reject 아님, status null, tail에 ENOENT 포함.
