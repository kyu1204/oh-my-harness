# L-06 worktree.ts — git worktree·자산 동기화·원장 시드

## 목적
격리 worktree 수명주기와 아키텍트 자산 동기화, 원장 시드(해시 기준). 모든 git은 `execFile`(셸 없음).

## 파일
- 구현: `src/loop/worktree.ts`
- 테스트: `tests/unit/loop-worktree.test.ts` (temp git repo, `git init` + 초기 커밋)
- depends: L-01(hashLedger), L-04(loopPaths, atomicWrite)

## 시그니처
```ts
export class WorktreeError extends Error {}
export async function git(cwd: string, args: string[]): Promise<string>   // execFile, trim stdout, 실패 시 WorktreeError(stderr)
export async function headOf(cwd: string): Promise<string>                  // rev-parse HEAD
export async function currentBranch(cwd: string): Promise<string>           // rev-parse --abbrev-ref HEAD
export interface EnsureResult { path: string; reusedBranch: boolean }
export async function ensureWorktree(projectDir: string): Promise<EnsureResult>
export const ARCHITECT_ASSETS = ["docs/work-orders" /* cfg.workOrders로 대체 */, ".claude", ".codex", ".pi", ".omh/hooks", "CLAUDE.md", "AGENTS.md", "harness.yaml"] as const;
export async function syncAssets(projectDir: string, worktree: string, workOrders: string): Promise<string[]>  // 복사된 상대경로
export interface SeedResult { seeded: boolean; hash: string }
export async function seedLedger(projectDir: string, worktree: string, ledger: string): Promise<SeedResult>
```

## ensureWorktree (결정 D8)
1. `currentBranch(projectDir) === "omh-loop"` → `WorktreeError("main tree is on omh-loop")`.
2. `git worktree prune`.
3. `git worktree list --porcelain`에 worktree 경로가 등록돼 있으면 `{path, reusedBranch:false}` 반환.
4. 미등록인데 디렉터리 존재: 비어 있으면 rmdir, 아니면 `WorktreeError("... run 'omh loop clean'")`.
5. 브랜치 존재(`rev-parse --verify --quiet refs/heads/omh-loop` 성공) → `worktree add <path> omh-loop`, `reusedBranch:true`; 아니면 `worktree add -b omh-loop <path>`.

## syncAssets (D9)
목록: `[workOrders, ".claude", ".codex", ".pi", ".omh/hooks", "CLAUDE.md", "AGENTS.md", "harness.yaml"]`. 각 항목: 소스 없으면 skip; 있으면 `fs.cp(src, dst, {recursive:true, force:true})`; 실패는 throw(WorktreeError로 감싸기). 반환: 복사한 항목.

## seedLedger (D7)
- `main = projectDir/ledger` 없으면 `WorktreeError("ledger missing")`.
- `hash = hashLedger(main 내용)`. `seed.json`의 `{ledgerHash}` 읽기(없으면 null).
- worktree 원장 없음 **또는** hash !== seed.ledgerHash → 부모 디렉터리 mkdir -p → 복사 → `atomicWrite(seed.json, {ledgerHash: hash})` → `{seeded:true}`.
- 아니면 `{seeded:false}`.

## removeWorktree
- 등록돼 있으면 `git worktree remove --force --force <path>`; 디렉터리 잔존 시 `rm -rf`. `git worktree prune`. `opts.branch`면 `git branch -D omh-loop`(없으면 무시).

## 테스트 케이스
1. 신규: worktree 생성, 브랜치 omh-loop, `reusedBranch=false`.
2. worktree 제거 후 브랜치만 남은 상태에서 ensure → `reusedBranch=true`.
3. 미등록·비어있지 않은 디렉터리 → WorktreeError 메시지에 `omh loop clean`.
4. 메인이 omh-loop로 checkout된 상태 → WorktreeError.
5. syncAssets: 미커밋 `.claude/settings.json`·`docs/work-orders/T-1.md`·`CLAUDE.md` 생성 후 호출 → worktree에 존재, 반환 목록 포함; `.codex` 없으면 skip.
6. seedLedger: 첫 호출 seeded true; 같은 내용 재호출 false; worktree 원장을 수정(체크)한 뒤 메인 원장 불변 → false(체크 유지); 메인 원장 내용 변경 → true(재시드).
7. worktree에 dirty 파일 만들고 removeWorktree → 디렉터리 없음, 브랜치 존재; `{branch:true}` → 브랜치도 없음.
- **역검증**: seedLedger에서 해시 비교를 제거하면 케이스 6의 "체크 유지" 서브케이스가 실패해야 한다.
