# L-07 스키마·LoopConfig 확장

## 목적
`shellSafePath` → `relPath`(따옴표 허용, canonical 상대경로만 강제), knob 4개 추가.

## 파일
- `src/core/harness-schema.ts`, `src/core/merged-config.ts`
- 테스트: `tests/unit/loop-config.test.ts` (기존 파일 수정)

## 변경
- `relPath = z.string().min(1).refine(canonical)` — canonical: `/`로 시작 안 함, 세그먼트에 ``·`.`·`..` 없음(후행 `/` 금지 포함). 정규식 `/^[^'"`$\\\n]+$/` 삭제. `\n` 포함은 refine에서 거부.
- loop 스키마 추가: `limitBackoff: z.number().positive().default(1800)`, `emptyBackoff: ...default(300)`, `stallStreak: z.number().int().positive().default(3)`, `turnTimeout: z.number().positive().default(7200)`.
- `LoopConfig`(merged-config.ts)에 같은 4필드 추가(주석 1줄씩).

## 테스트
- 기존 "rejects quotes..." 케이스 → **삭제**하고 "accepts quotes in paths now that no shell interpolation exists"로 교체(`docs/it's` 통과).
- canonical 케이스 유지(`./x`, `../x`, `/abs`, `docs/./x`, 후행 `/`, 개행 포함 거부).
- 4 knob 기본값·0/음수 거부·stallStreak 소수 거부.
- `harnessToMergedConfigV2` 결과의 `loop`에 4필드 존재.

`npx vitest run tests/unit/loop-config.test.ts && npm run lint`
