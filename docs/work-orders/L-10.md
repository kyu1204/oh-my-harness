# L-10 codex-config normalizeMatcher 일반화

## 목적
`Edit|Write|Bash` 같은 복합 matcher에도 Codex `apply_patch` 별칭이 붙도록.

## 파일
- `src/generators/codex-config.ts` `normalizeMatcher` (이 함수 외 변경 금지)
- 테스트: `tests/unit/codex-config-generator.test.ts` 케이스 추가

## 변경
```ts
const parts = matcher.split("|");
if (parts.some(p => p === "Edit" || p === "Write") && !parts.includes("apply_patch")) return `${matcher}|apply_patch`;
return matcher;
```

## 테스트
- `Edit|Write|Bash` → `Edit|Write|Bash|apply_patch`; `Bash` → 불변; `Edit|apply_patch` → 불변; 기존 케이스 유지.

`npx vitest run tests/unit/codex-config-generator.test.ts`
