# L-11 loop-assets 축소·generator/uninstall/converter 배선

## 목적
생성 셸 러너 제거. 루프 자산 = SKILL.md 하나. 비활성화·uninstall은 TS stop 경로 + worktree 해제.

## 파일
- `src/generators/loop-assets.ts`: `computeLoopAssets`(SKILL.md, 본문 `renderSkill` from `src/loop/protocol.ts`), `loopAssetPaths`(`.claude/skills/omh-loop` 디렉터리 1개)만 남김. 삭제: `renderRunner`, `runtimeCommand`, `shellSingleQuote`, `stopRunningLoop`, `renderLoopProtocol`, `renderSkill`, `execFileSync` import.
- `src/core/harness-converter-v2.ts`: `renderProtocolSection` import 경로 교체.
- `src/core/generator.ts`: 자산 쓰기는 `atomicWrite`(state.ts) 사용; `!config.loop` → `await stopLoop(projectDir)`(L-12에서 구현되므로 **이 태스크에서는 `src/loop/control.ts`에 `stopLoop` 임시 구현 금지** — 대신 `src/cli/commands/loop.ts`가 아직 없으면 `src/loop/stop.ts`에 `stopLoop(projectDir, {graceMs})`를 두고 L-12가 재사용) → `removeWorktree` (없으면 무시) → `loopAssetPaths` rm. gitignore 항목 유지(`.omh/state/`, isolate면 `.omh/loop/worktree/`).
- `src/core/uninstall.ts`: `stopRunningLoop` → `stopLoop` + `removeWorktree`.
- 테스트: `tests/unit/loop-assets.test.ts` **재작성**(SKILL.md 존재·내용이 renderSkill과 동일·plan 대칭·loop off면 자산 없음·disable 시 SKILL 디렉터리 삭제·`.omh/loop/run.sh` 절대 생성 안 됨·gitignore worktree), `tests/unit/uninstall-loop.test.ts` 갱신, `tests/unit/loop-runner-behavior.test.ts` **삭제**.

## stopLoop(projectDir, {graceMs=10000}) (src/loop/stop.ts)
1. `readRun` 없으면 return. 2. stop 플래그 작성. 3. `isRunLive(run)` 아니면 run.json 삭제 후 return. 4. `process.kill(-run.pid, "SIGTERM")`; 100ms 폴링으로 `process.kill(-run.pid, 0)`이 ESRCH 던질 때까지 graceMs 대기; 초과 시 `SIGKILL`. 5. run.json 잔존 시 삭제.
