# L-12 omh loop CLI (start/run/stop/status/clean)

## 목적
사용자·스킬 진입점. 프리플라이트, detached spawn, 정지, 상태, 정리.

## 파일
- `src/cli/commands/loop.ts`, `src/cli/index.ts`(`loop` 서브커맨드 패밀리, `hook` 패턴, lazy import, 공통 `-d, --project-dir`)
- 테스트: `tests/unit/cli-loop.test.ts`
- depends: L-08, L-11(stopLoop)

## 시그니처 (모두 `Promise<{exitCode: number}>`)
```ts
loopStartCommand({projectDir?, spawnImpl?})   // spawnImpl 주입으로 테스트
loopRunCommand({projectDir?, runId})          // runSupervisor 호출, exit 매핑: complete 0 / stopped 0 / already-running 3 / failed 1
loopStopCommand({projectDir?, now?})          // stopLoop(graceMs: now ? 1000 : 10000)
loopStatusCommand({projectDir?})              // run.json 유무·생존·iteration·이벤트 경로 출력
loopCleanCommand({projectDir?, branch?})      // stopLoop → removeWorktree({branch}) → stale run.json/stop 삭제
```

## start 프리플라이트 (순서대로, 실패 시 chalk.red 메시지 + exitCode 1)
1. `process.platform === "win32"` → "loop is POSIX-only".
2. `git rev-parse --show-toplevel` 실패 → not a git repository.
3. harness.yaml 로드·파싱(`HarnessConfigSchema`), `loop.enabled` 아니면 에러.
4. `currentBranch === "omh-loop"` → 에러.
5. `cfg.ledger` 파일 없음 → 에러. `cfg.workOrders` 디렉터리에 `*.md` 0개 → 에러.
6. `readRun()` 있고 `isRunLive` → "already running (pid …)" exitCode 1.
7. `pruneRuns(projectDir, 5)`; **stop 플래그 삭제**(D4).
8. runId = `<YYYYMMDD-HHmmss>-<4hex>`; `spawnImpl(process.execPath, [...process.execArgv, process.argv[1], "loop","run","--run-id",runId,"-d",projectDir], {detached:true, stdio:["ignore",fd,fd], env:{...process.env, OMH_SKIP_VERSION_CHECK:"1"}})` — fd = `runDir/supervisor.log`.
9. 100ms 폴링 최대 15s: `readRun()?.runId === runId` → 성공: `child.unref()`, 출력(runId·pid·이벤트 경로·`omh loop status`), exitCode 0. 자식이 먼저 종료 → exitCode = 자식 코드(3이면 already running 메시지).

## 테스트 케이스
- 프리플라이트 5종 각각 exitCode 1 + 메시지(win32는 `process.platform` 스텁).
- 성공 경로: spawnImpl 스텁이 run.json을 써주는 가짜 자식 반환 → exitCode 0, unref 호출, stop 플래그가 사전에 존재했다면 삭제됨.
- 자식이 exit 3 → exitCode 3.
- status: run 없음 → "no active loop" exit 0; run 있음(살아있는 pid 스텁) → runId·iteration 출력.
- stop: run 없음 → exit 0 메시지; run 있음 → stopLoop 호출(스파이).
- clean: worktree 제거 호출, stale 파일 삭제.
