# L-13 e2e — tsx로 실제 start/stop

## 목적
detached spawn·프로세스 그룹 kill을 진짜 프로세스로 검증.

## 파일
- 테스트: `tests/unit/loop-e2e.test.ts` (`SLOW = 30_000`)
- depends: L-12

## 준비
temp git repo + harness.yaml(`loop: {isolate:false, interval:1, runtime:claude}`) + `omh sync` 상당(`generate()` 직접 호출) + 원장 1태스크 + 지시서 1개 + stub `claude`(PATH 선두): 원장 체크·커밋·sentinel 출력.
CLI 실행: `spawnSync(node_modules/.bin/tsx, [bin/oh-my-harness.ts, "loop", "start", "-d", dir], {env: {...process.env, PATH: stub:PATH, OMH_SKIP_VERSION_CHECK:"1"}})`.

## 케이스
1. start exit 0 이고 3초 내 반환; run.json 존재; 이후 최대 20초 폴링으로 이벤트에 `complete`; run.json 사라짐.
2. stub이 `sleep 30`인 상태로 start → `loop stop --now` → 15초 내 `process.kill(-pid, 0)`이 ESRCH; 이벤트에 `stopped`.
3. start 2회 연속 → 두 번째 exitCode 3 또는 1(already running).

## 검증
`npx vitest run tests/unit/loop-e2e.test.ts`
