# L-20 Codex argv에 --dangerously-bypass-hook-trust

## 목적
Codex 0.149는 프로젝트 `.codex/hooks.json` 훅을 trust가 영속 저장되기 전엔 실행하지 않는다(실 QA: 글로벌 훅만 실행, PreToolUse 무발동). 무인 루프는 승인 프롬프트를 띄울 수 없으므로 `--dangerously-bypass-approvals-and-sandbox`와 같은 이유로 `--dangerously-bypass-hook-trust`를 함께 넘긴다.

- 테스트: `tests/unit/loop-runtime.test.ts` argv 기대값 갱신
