# L-22 QA 픽스처 스크립트 dist 폴백 (CI)

## 지시
CI는 빌드 없이 `npm test`를 돌리므로 `dist/bin/oh-my-harness.js`가 없어 `loop-qa-fixture.test.ts`가 실패. 스크립트는 dist가 없거나 `OMH_QA_FORCE_TSX=1`이면 `node_modules/.bin/tsx bin/oh-my-harness.ts`로 sync를 실행한다. 테스트: `OMH_QA_FORCE_TSX=1`로 한 번 더 실행해 동일 결과.
