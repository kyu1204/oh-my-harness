# L-25 acquireRun stale 회수 레이스 봉합

## 지시
stale 판정 후의 회수를 두 단계로: ① `mkdir run.json.reclaim` 원자 잠금(내부에 pid 기록; 이미 있고 그 pid가 살아있으면 false, 죽었으면 정리 후 재시도 1회) ② 잠금 안에서 `run.json`을 다시 읽어 **관측한 stale 레코드(pid·runId·startedAt)와 동일할 때만** unlink → link. 다르면(다른 러너가 이미 새로 획득) false. `export function reclaimStaleRun(projectDir, observed: RunInfo): boolean`로 분리해 단위 테스트: 디스크 레코드가 observed와 다르면 false·디스크 불변; 같으면 true·삭제; reclaim 디렉터리에 살아있는 pid → false; 죽은 pid → 회수 성공.
