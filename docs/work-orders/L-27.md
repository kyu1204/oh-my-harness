# L-27 state/stop 동시성 봉합

## 지시
(a) updateRun에 releaseRun과 같은 소유권 가드(runId+pid) — 시그니처 updateRun(projectDir, runId, patch). (b) stopLoop·clean의 최종 rm은 스냅샷(runId·pid) 재확인 후에만. (c) stopLoop는 run.json이 없어도 stop 플래그를 무조건 기록(획득 창의 stop 유실 방지); loopStopCommand도 run 부재 시 stopLoop 호출. (d) reclaim 잠금 생성을 mkdtemp+rename 원자화(반쯤 쓰인 잠금 상태 제거 — ENOENT 크래시 소멸). (e) 턴 종료 시 updateRun으로 childPid 제거; stop의 childPid 시그널은 ps argv에 run.runtime 바이너리명이 보일 때만(정체 검증). (f) start는 stale 회수 전 childPid 그룹 생존 확인 — 살아있으면 'orphaned turn still running; omh loop stop first'로 거부.
